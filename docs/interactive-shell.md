# 交互模式使用说明

`quarkpan interactive`（或直接 `quarkpan`）进入交互 shell，采用 prompt_toolkit 实现，
支持行编辑、历史、Tab 补全与可滚动候选菜单。

---

## 快捷键

| 按键 | 作用 |
|---|---|
| `Tab` | 补全命令名 / 当前参数的文件名、文件夹名 |
| `Tab` `Tab` | 菜单已弹出时切换候选 |
| `↑` / `↓` | 翻阅历史命令 |
| `←` / `→` | 移动光标 |
| `Ctrl-A` / `Ctrl-E` | 跳到行首 / 行尾 |
| `Ctrl-R` | 反向搜索历史 |
| `Ctrl-C` | 中断当前输入，不退出 |
| `Ctrl-D` | 退出 |

历史保存在 `get_config_dir()/shell_history`（默认 `./config/`，可用 `QUARK_CONFIG_DIR` 指定）。

---

## 补全规则

### 命令名

行首输入前缀按 `Tab`，候选右侧显示命令说明，例如 `do` → `download  下载文件`。

### 路径参数

命令之后按 `Tab` 补全路径，支持四种前缀写法：

| 写法 | 含义 | 示例（位于 `/夸克精选壁纸/` 时） |
|---|---|---|
| （空） | 当前目录 | `cd 子<Tab>` → `'子目录'` |
| `..` | 上级目录 | `cd ../<Tab>` → `../'夸克精选壁纸'` |
| `../..` | 上两级 | `cd ../../<Tab>` |
| `/` | 根目录 | `cd /夸<Tab>` → `/'夸克精选壁纸'` |
| `子目录/` | 指定子目录内部 | `download 子目录/<Tab>` |

插入的文本会保留目录前缀；文件名部分经 `shlex.quote` 转义，所以带空格的名字会变成
`'落幕曲 1.5.4.zip'`，不会被 `shlex.split` 拆碎。

### 按命令区分的候选类型

| 命令 | 补全内容 |
|---|---|
| `cd` / `ls` / `list` | 只补文件夹（另有 `..`，根目录下不出现） |
| `move` | 第 1 个参数补文件 + 文件夹，第 2 个参数只补文件夹 |
| `rename` | 只补第 1 个参数（第 2 个是新名字） |
| `download` / `rm` / `info` / `share` / `dl` 等 | 文件 + 文件夹 |
| `search` / `find` / `mkdir` / `upload` / `save` / 无参命令 | 不补路径 |

### 目录缓存与状态栏

- 登录后立即在后台预加载当前目录，所以**首次**按 `Tab` 就能补出文件名，不必先 `ls`
- 按 `Tab` 时若缓存仍未就绪，最多等待 2 秒
- 缓存按 `folder_id` 存放，访问过的目录会被记住，`cd ../` 这类回退是即时的
- 底部状态栏显示：当前路径、条目数、快捷键提示；加载中显示 `⏳ 正在加载目录…`

## 已知限制

以下是当前实现不做的事，遇到时的表现和规避方式一并列出。

### 1. 绝对路径中间的 `..` 不解析

`/a/../b` 这种写法解析失败，直接不给候选。前缀里的 `..` 只支持出现在**开头连续段**
（`../`、`../../`），放在中间或后面一律放弃。

规避：用相对路径回退，或先 `cd` 到目标目录再补全。

### 2. 目录加载失败后不会自动重试

某个目录拉取失败（网络抖动、权限等），会记住失败状态，之后对该目录的补全会直接返回空，
状态栏提示「目录加载失败，执行 ls 可重试」。

规避：执行一次 `ls`（或 `ls <路径>`）即可刷新缓存并清除失败标记。

### 3. 只补全已加载过的目录

`子目录/` 这种前缀需要在当前目录的缓存里找到该子目录的 `fid`。如果当前目录还没加载完，
首次会阻塞最多 1 秒去取父目录；仍失败就没有候选。

### 4. `cd` 只补文件夹

`cd 深` 在 `深文件.txt` 是文件时返回空，这是正确行为，不是 bug。
需要选文件请用 `download` / `info` / `rm` 等命令。

### 5. 不补全本地路径

`upload <本地文件>` 的参数是本机文件系统路径，本次未接 `PathCompleter`，
需要手动输入完整路径。

### 6. 缓存不会因增删改自动失效

`rm` / `rename` / `move` / 上传之后，缓存仍是操作前的快照，再次 `Tab` 可能补出已删除或
旧名字的条目。命令执行本身不受影响（按名字解析时会重新查 API）。

规避：操作后执行 `ls` 刷新。

### 7. 文件名以引号开头时不识别

`_unquote` 只剥掉用户输入的前导引号；如果文件名本身以 `'` 或 `"` 开头，前缀匹配可能失效。

### 8. 底部状态栏依赖终端

状态栏是 prompt_toolkit 的辅助行，某些终端（不响应光标位置查询 CPR 的、或把输出重定向
到管道的场景）不会渲染它，功能不受影响。

## 相关实现

- `quark_client/cli/interactive.py`
  - `ShellCompleter` —— 补全逻辑（命令名、路径前缀、`shlex.quote`）
  - `resolve_completion_dir()` —— 把 `..`、`/`、`子目录/` 解析成 `folder_id`
  - `load_entries()` / `_fetch_entries()` —— 按 `folder_id` 的后台缓存加载
  - `_bottom_toolbar()` —— 底部状态栏
- 设计过程与验证记录见 `docs/PLAN-interactive-shell.md`
